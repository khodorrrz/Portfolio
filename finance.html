Track spending across USD and LBP

I built a bilingual personal finance app for Lebanese spending habits, including mixed-currency wallets, receipt OCR and SMS transaction drafts. I also containerized it, built the Azure DevOps pipeline, and deployed it to Azure with Key Vault-backed secrets and managed identities.

From Docker to Azure

The app runs as two containers on App Service, with a Python Function App handling statements and recurring work. The deployment is repeatable and the secrets are not in the repository.

  1. Build & push

    Azure DevOps YAML pipeline runs pytest, builds both Docker images, and pushes them to Azure Container Registry (build 1m18s).

  2. Deploy

    Deploys the API and frontend to App Service and the statement worker to a Python Function App (deploy 3m37s).

  3. Secure & observe

    Azure SQL through Key Vault and system-assigned managed identities; TLS enforced; Application Insights, Log Analytics, and budget alerts.

Engineering notes

A review queue gives users a chance to check imported amounts and categories before committing them. Reporting keeps currency and exchange-rate context visible.
