# Portfolio design

The portfolio is an expedition across a copper planet. Orange terrain and equipment details sit against charcoal space. Warm white lettering and Bricolage Grotesque carry the content. Shared case-study and CV surfaces use the same dark neutrals, orange actions, and fine rules. Authored diagrams use copper and charcoal. Source screenshots retain their original colors.

The homepage opens at ground level beside the rocket. A brief camera descent settles on the landing site. The astronaut greets visitors as soon as the scene loads. The speech bubble follows the astronaut and reveals its text progressively. Its size is reserved for the full line so it stays still while typing. With voice on, the reveal follows the narration playback. Reduced motion and screen readers receive the full caption immediately. The guide takes slower strides between checkpoints. On arrival, they turn back, point toward the signs, and use short hops, waves, and nods. Visitors move between stations by scrolling. Selecting the astronaut or the voice control toggles voice narration and keeps its on/off state visible. Each station has a bundled English narration clip synthesized with Microsoft David.

The rocket lifts briefly above its pad, and the scanner sweeps the ground. Visitors can select the models or use controls that appear on keyboard focus. The route crosses copper rock fields along a trail with amber marker lights. Four stops are marked by riveted sign planks. Their HTML links share the perspective of the 3D planks. Departing signs fade before they reach the guide, who follows a lane offset from the station path in local planet coordinates. On phones the dialogue sits below the guide. Only the closest stop is interactive.

Each wheel gesture, swipe, or navigation key moves one checkpoint. The terrain rotates around the camera's horizontal axis. The first departure launches the rocket from its pad. Scrolling past the last checkpoint sends the guide off-screen in a low-gravity jump before bringing Selected Work into view. Reduced motion cuts directly to the destination. Camera distance and sign sizing adapt to the viewport. The project index provides the reading route if WebGL is unavailable or lost.

Project, CV, and contact links open their own pages. The Back to portfolio link at the top uses browser history for visitors arriving from the site and links to the portfolio on direct visits. The contact page offers an email link and GitHub.

The retrieval lab pairs the original exploded circuit model with the sample request. Dragging or using the rotate button changes its orientation. Assemble and Explode reveal how the layers fit. The 3D renderer draws on interaction and resize. A render from the same scene provides a fallback when WebGL is unavailable. Reduced-motion preferences make model changes immediate. Stages are selected directly, with no animated packet.

Work & experience features the Coderaas full-stack role first, then groups eight case studies into production and client work, apps and experiences, applied AI, and engineering tools. An Experience chapter follows the project groups, and the project index links directly to each group and to experience. Every entry has a labeled source capture, demo still, or architecture diagram. The featured Coderaas card represents the platform role as a whole; LiveSyncher appears inside the case study as a supporting subsystem. The case study leads with the React frontend, Express APIs, and data and access work. Its LiveSyncher exhibit includes a real setup capture and a step-through from cloud event to local record. Experience, the source PDF, and contact remain directly reachable.

The model uses Three.js r160 from the upstream GitHub release under the MIT license in vendor/three-LICENSE.txt. The locally hosted Bricolage Grotesque font is covered by assets/bricolage-LICENSE.txt.
The selected case studies use interactive exhibits grounded in the source projects. The RAG exhibit compares real captures, the security exhibit follows page scroll through six checkpoints with a pinned pipeline map and a report outcome for each fixture, and ASL shows two looping animations from the original recordings. Barberous presents its English and Arabic mobile layouts as separate views. Motion is reserved for the planet, model, and ASL recordings, and honors the reduced-motion preference.

The gallery uses compact thumbnail rows on phones, while case studies reserve larger media for the evidence itself. ASL loads only the selected animation while its exhibit is visible and shows a still with reduced motion or when paused. On wide screens, evidence and its architecture walkthrough share a two-column artifact; wide captures use the full reading width. Architecture walkthroughs are always visible; only the long security phase lists and the optional Windows setup capture use disclosure. The retrieval lab stacks its model and trace below desktop width. Contact and error pages center their message between the header and footer.
