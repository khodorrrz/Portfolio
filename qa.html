Generate browser tests from how an app actually works

The orchestrator reads application source, derives scenarios for pages and roles, drives a browser, and records evidence in a structured ledger.

Anatomy of an audit

Architecture walkthrough

01Read source

Build a graph of routes, components, API contracts and auth.

02Plan

Select scenarios for each relevant page and role.

03Exercise

Drive the real application and record outcomes with evidence.

04Deliver

Generate regression tests and a report from the ledger.

Engineering notes

Source discovery provides routes, contracts and authorization context. Browser exploration supplies observations. Reporting derives from the ledger, and passing scenarios can become Playwright regression tests.
